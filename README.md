# Serde.Toml

A TOML format serializer/deserializer for .NET using [Serde](https://github.com/serdedotnet/serde).

## Status

This is a work in progress. The structure is set up but implementation is not yet complete.

## Building

```bash
dotnet build
```

## Testing

```bash
dotnet test
```

## Benchmarking

```bash
dotnet run --project bench -c Release
```
